Ce que fait Pince

↵

Un raccourci, un panneau, ↩

⇧⌘Espace ouvre un panneau par-dessus n'importe quelle app. Quelques lettres, les flèches, ↩ : l'élément est de retour dans le presse-papiers, ou collé directement si vous le demandez.

◉

Il reconnaît ce qu'il garde

Lien, adresse, couleur, JSON, code, chemin, image, fichiers : chaque copie est reconnue et affichée en conséquence, avec l'app d'origine. Une couleur montre sa pastille, un JSON se formate.

⌂

Discret et local

L'historique est un fichier SQLite sur votre Mac. Les copies marquées confidentielles par les gestionnaires de mots de passe ne sont jamais enregistrées, et vous pouvez exclure des apps.

Installer Pince

L'app est signée ad hoc, sans certificat Apple Developer : au premier lancement, macOS 26 demande une confirmation. Quatre étapes, une seule fois.

  1. Ouvrez le DMG, glissez Pince dans le dossier Applications, puis double-cliquez sur l'app.
  2. Dans la boîte « Apple n'a pas pu vérifier… », cliquez « Terminé » (pas « Placer dans la corbeille »).
  3. Ouvrez Réglages Système › Confidentialité et sécurité, descendez jusqu'à « Pince a été bloqué… », cliquez « Ouvrir quand même », authentifiez-vous, puis « Ouvrir ».
  4. C'est tout. Cette manipulation n'est demandée qu'une seule fois par téléchargement ; ensuite Pince s'ouvre normalement.

Pourquoi cet avertissement au premier lancement ?

Pince n'est ni signé avec un certificat Apple Developer ni notarisé, alors macOS bloque le premier lancement. Depuis macOS 15, l'ancien contournement « Contrôle-clic, puis Ouvrir » n'existe plus pour les apps non notarisées : le passage par Réglages Système est le seul chemin.

Comment vérifier le fichier téléchargé ?

Chaque version publie son empreinte SHA-256. Dans le dossier du téléchargement : shasum -a 256 -c Pince-X.Y.Z.dmg.sha256.

Confidentialité

Pince travaille en local, sur votre Mac, et rien d'autre.

  • Vos données restent sur votre Mac
  • Aucun compte, aucune inscription
  • Aucune télémétrie, aucun traceur
  • Un seul appel réseau : la lecture de la dernière version publiée sur GitHub, désactivable dans les réglages
