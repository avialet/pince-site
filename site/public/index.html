Un raccourci, un panneau, entrée

⌃⇧Espace ouvre un panneau par-dessus n'importe quelle app. Quelques lettres, les flèches, puis ↩ : l'élément revient dans le presse-papiers, ou se colle directement.

Il reconnaît ce qu'il garde

Lien, adresse, couleur, JSON, code, chemin, image, fichiers : chaque copie est affichée pour ce qu'elle est, avec l'app d'origine et son ancienneté.

Installer Pince

Pince est signée sans certificat Apple Developer : au premier lancement, macOS demande une confirmation. Une seule fois.

  1. Ouvrez le DMG

    Glissez Pince dans Applications, puis double-cliquez sur l'app.

  2. Cliquez « Terminé »

    Dans la boîte « Apple n'a pas pu vérifier… », pas « Placer dans la corbeille ».

  3. Ouvrez quand même

    Réglages Système, Confidentialité et sécurité : en bas, « Pince a été bloqué », puis « Ouvrir quand même ».

  4. C'est fait

    Les lancements suivants sont normaux, et les mises à jour s'installent depuis l'app.

Télécharger

Pourquoi cet avertissement au premier lancement ?
Pince n'est ni signée avec un certificat Apple Developer ni notarisée, alors macOS bloque le premier lancement. Depuis macOS 15, le contournement « Contrôle-clic, puis Ouvrir » n'existe plus : le passage par Réglages Système est le seul chemin.
Comment vérifier le fichier téléchargé ?
Chaque version publie son empreinte SHA-256. Dans le dossier du téléchargement : shasum -a 256 -c Pince-X.Y.Z.dmg.sha256.

Chez vous

L'historique est un fichier SQLite sur votre Mac, les images sont rangées à côté. Les copies que les gestionnaires de mots de passe marquent confidentielles ne sont jamais enregistrées, et vous pouvez exclure des apps. Le seul appel réseau est la lecture de la dernière version publiée sur GitHub, désactivable dans les réglages.

~/Library/Application Support/Pince/pince.sqlite
